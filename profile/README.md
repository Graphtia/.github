# Graphtia

**Codebase intelligence for developers and coding agents.**

**[Download Explorer Free](https://graphtia.com/downloads)** · [Installation guide](https://graphtia.com/docs/installing-explorer) · [Website](https://graphtia.com/)

## Graphtia Explorer

Explore how a codebase fits together before you change it. Map your code locally, follow callers and dependencies, and jump from the graph to the exact source. Supported coding agents can query the same code structure through [Graphtia's integrations](https://graphtia.com/docs/integrations).

**Public beta for Windows x64 and Ubuntu x64.** No invitation is required. Download the app, then sign in with a free Graphtia account. [Explore Free features and limits](https://graphtia.com/docs/early-access).

## Graphtia Governance

[Governance](https://graphtia.com/docs/governance-overview) is in development and not publicly available. It's designed to make longer-running engineering work reviewable by connecting plans, constraints, execution records, and evidence.
